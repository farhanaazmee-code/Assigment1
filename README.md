Python Projects

This folder contains two simple Python projects developed for academic purposes to practice and demonstrate basic Python programming concepts: a Student Grade Calculator and a Shopping Cart.

Projects

1. Student Grade Calculator
The Student Grade Calculator takes a student's name and marks for three subjects. It calculates the total marks and average marks, then assigns a grade based on the average.

Features:
* Takes the student's name as input.
* Takes marks for three subjects.
* Calculates total marks.
* Calculates average marks.
* Assigns a grade based on the average.
* Displays the student's name, total, average, and grade.
Grade System:
* 80 or above → A+
* 70–79 → A
* 60–69 → B
* 50–59 → C
* Below 50 → F

2. Shopping Cart

The Shopping Cart program takes a customer's name and information for three products. It calculates the subtotal, applies a discount based on the subtotal, and displays the final total.

Features:
* Takes the customer's name as input.
* Takes the names and prices of three products.
* Calculates the subtotal.
* Applies a discount based on the subtotal.
* Calculates the final total after discount.
* Displays the customer and purchase information.
Discount System:
* 5000 or above → 20% discount
* 3000–4999 → 10% discount
* 1000–2999 → 5% discount
* Below 1000 → No discount

Technologies Used
* Python
* Python built-in input() function
* Conditional statements (if, elif, else)
* Arithmetic operations
* Variables
* Formatted output

Setup and Run Instructions
Prerequisites
Make sure Python is installed on your computer.

Run Student Grade Calculator
Open a terminal and navigate to the Student Grade Calculator folder, then run:
python grade_calculator.py
Enter the student's name and marks for the three subjects when prompted.

Run Shopping Cart
Navigate to the Shopping Cart folder and run:
python shopping_cart.py
Enter the customer's name, product names, and prices when prompted.
